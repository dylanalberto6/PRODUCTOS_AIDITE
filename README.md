# Catalogo Aidite

Pagina estatica lista para publicar como catalogo de productos.

Archivos principales:

- `index.html`: contenido del catalogo, productos, textos y enlaces a WhatsApp.
- `styles.css`: diseno visual responsive para celular y escritorio.
- `assets/`: imagenes de los productos.

Pendiente:

- Reemplazar cada texto `Precio fijo: por confirmar` por el precio final de cada producto.
- Publicar la carpeta en un servicio como Netlify, Vercel o GitHub Pages para obtener un link publico.
